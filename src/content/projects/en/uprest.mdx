Uprest is a local HTTP-to-Redis proxy for applications that use the [Upstash Redis REST API](https://upstash.com/docs/redis/features/restapi). It forwards requests to a real Redis server, so applications can keep using `@upstash/redis` during local development and CI without an Upstash database.

I originally used [serverless-redis-http](https://github.com/hiett/serverless-redis-http) (SRH) for this, but it appears to be unmaintained and newer `@upstash/redis` versions break it, so I decided to build a replacement myself. Uprest supports Redis commands, pipelines, transactions, Pub/Sub over SSE, JSON and RESP2 responses, bearer or query-token authentication, and recent `@upstash/ratelimit` versions. It is published as multi-architecture Docker images and prebuilt binaries for Linux, macOS, and Windows.
