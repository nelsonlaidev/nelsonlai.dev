このプライバシーポリシーは、お客様がサービスをご利用になる際の情報の収集、使用、開示に関する当社の方針と手続きを説明し、お客様のプライバシーの権利と法律による保護についてお知らせするものです。

当社はお客様の個人データを使用してサービスを提供・改善します。サービスをご利用いただくことで、このプライバシーポリシーに従った情報の収集と使用に同意したものとみなされます。

## 解釈と定義

### 解釈

以下の用語は、本書においてそれぞれ定められた意味を持ちます。単数形・複数形のいずれでも同じ意味で使用します。

### 定義

このプライバシーポリシーの目的において：

- **アカウント**とは、お客様が当社のサービスまたはサービスの一部にアクセスするために作成された固有のアカウントを意味します。
- **アフィリエイト**とは、ある当事者を支配し、支配されており、または共同支配下にある法人を意味します。「支配」とは、取締役その他の管理機関の選出に投票できる株式、持分その他の有価証券の50%以上の所有を意味します。
- **会社**（本契約において「会社」、「当社」、「私たち」または「私たちの」と呼ばれます）は、nelsonlai.devを指します。
- **クッキー**とは、ウェブサイトによってお客様のコンピューター、モバイルデバイス、またはその他のデバイスに配置される小さなファイルであり、そのウェブサイトでのお客様の閲覧履歴の詳細を多くの用途の中に含んでいます。
- **国**は、香港特別行政区（中国）を指します。
- **デバイス**とは、コンピューター、携帯電話、デジタルタブレットなどのサービスにアクセスできる任意のデバイスを意味します。
- **個人データ**とは、識別された、または識別可能な個人に関するあらゆる情報です。
- **サービス**とはウェブサイトを指します。
- **サービスプロバイダー**とは、会社に代わってデータを処理する自然人または法人を意味します。これは、サービスを促進するため、会社に代わってサービスを提供するため、サービスに関連するサービスを実行するため、またはサービスの使用方法の分析を会社が行うのを支援するために会社によって雇用されたサードパーティの企業または個人を指します。
- **サードパーティソーシャルメディアサービス**とは、ユーザーがサービスを使用するためにログインまたはアカウントを作成できる任意のウェブサイトまたはソーシャルネットワークウェブサイトを指します。
- **利用データ**とは、サービスの使用によって生成されたか、またはサービスインフラ自体から（例えば、ページ訪問の期間）自動的に収集されるデータを指します。
- **ウェブサイト**とは、[https://nelsonlai.dev](https://nelsonlai.dev) からアクセス可能な nelsonlai.dev を指します。
- **お客様**とは、サービスにアクセスし、またはサービスを利用する個人、あるいはその個人が代理してサービスにアクセスし、またはサービスを利用する会社その他の法人を意味します（該当する場合）。

## お客様の個人データの収集と使用

### 収集するデータの種類

#### 個人データ

当社のサービスをご利用いただく際、お客様に連絡または識別するために使用できる特定の個人を特定できる情報をご提供いただくよう求める場合があります。個人を特定できる情報には以下が含まれますが、これらに限定されません：

- 氏名、メールアドレス、プロフィール画像、アカウント識別子
- コメント、ゲストブックのメッセージ、通知設定
- 利用データ

#### 利用データ

利用データはサービス使用時に自動的に収集されます。

利用データには、IP アドレス、ブラウザー情報、ログイン時刻、セッション識別子が含まれる場合があります。これらはアカウントの保護や有効なセッションの表示に使用します。また、ブログへの匿名のいいねの回数を制限するため、IP アドレスから識別子を生成します。

有効なセッションの一覧におおよその場所を表示するため、セッションの IP アドレスを位置情報の照会に使用する場合があります。この照会では、該当の IP アドレスを位置情報照会サービスに送信します。

アクセス解析が有効な場合、Umami を使用してウェブサイトの訪問状況を把握します。解析スクリプトは、ページビュー、参照元ページ、ブラウザー、OS、デバイスの種類、おおよその場所を計測し、解析用クッキーは使用しません。

#### サードパーティソーシャルメディアサービスからの情報

会社は、次のサードパーティソーシャルメディアサービスを通じてアカウントを作成し、ログインしてサービスを使用することを許可しています：

- Google
- GitHub

Google または GitHub でログインする際、認証に必要なアカウント情報として、プロバイダーのアカウント識別子、氏名、メールアドレス、プロフィール画像などを受け取ります。連絡先リストへのアクセスは要求しません。

ウェブサイトを通じて、表示名、プロフィール画像、コメント、ゲストブックのメッセージ、通知設定を提供することもできます。これらの情報は、お客様が選択した機能を提供するために使用します。

#### トラッキング技術とクッキー

認証や言語設定のためにクッキーを使用し、テーマ設定を記憶するためにブラウザーのストレージを使用します。有効な場合は、Umami の解析スクリプトでウェブサイトの利用状況も把握します。

- **クッキーまたはブラウザクッキー。** クッキーはお客様のデバイスに配置された小さなファイルです。お客様はブラウザにすべてのクッキーを拒否するか、クッキーが送信されるときに通知するよう指示することができます。ただし、クッキーを受け入れない場合、当社のサービスの一部を使用できない場合があります。クッキーを拒否するようにブラウザを設定していない限り、当社のサービスはクッキーを使用する場合があります。
- **アクセス解析。** 有効な場合、Umami は解析用クッキーを使用せずに利用状況を計測します。閲覧されたページの把握やウェブサイトの改善に役立てます。

クッキーは「永続的」または「セッション」クッキーである場合があります。永続的クッキーはオフラインになってもお客様のパソコンまたはモバイルデバイスに残りますが、セッションクッキーはウェブブラウザを閉じるとすぐに削除されます。

当社は、以下の目的のためにセッションクッキーと永続的クッキーの両方を使用します：

- **必要/必須クッキー**

  種類：認証フローに応じたセッションクッキーまたは永続クッキー

  管理者：当社

  目的：これらのクッキーは、ウェブサイトを通じてお客様にサービスを提供し、その機能の一部を使用できるようにするために不可欠です。ユーザーの認証を助け、ユーザーアカウントの不正使用を防止します。これらのクッキーがなければ、お客様が要求したサービスを提供することができず、当社はこれらのクッキーのみをお客様にそれらのサービスを提供するために使用します。

- **機能クッキー**

  種類：永続的クッキー

  管理者：当社

  目的：これらのクッキーは言語設定を記憶します。テーマ設定にはブラウザーのストレージも使用するため、訪問のたびに選び直す必要がありません。

クッキーとブラウザーのストレージは、ブラウザーの設定で管理できます。認証用クッキーをブロックすると、ログインできない場合があります。これらの技術については hello@nelsonlai.dev までお問い合わせください。

### お客様の個人データの使用

会社は以下の目的のために個人データを使用する場合があります：

- **サービスの提供と維持のため**（サービスの使用状況の監視を含む）。
- **お客様のアカウントの管理のため：** サービスのユーザーとしてのお客様の登録を管理するため。お客様が提供する個人データにより、登録ユーザーとして利用可能なサービスのさまざまな機能にアクセスできます。
- **お客様への連絡：** 通知設定に従ってコメントや返信の通知を送信し、メールで寄せられたお問い合わせに対応します。
- **お客様のリクエストの管理のため：** お客様からのリクエストに対応し、管理するため。
- **事業譲渡のため：** 当社の資産の一部または全部の合併、分割、事業再構築、組織再編、解散、その他の売却または移転を評価または実施するために情報を使用する場合があります（継続企業としてまたは破産、清算または類似の手続きの一部として、当社がサービスユーザーについて保有する個人データが移転資産に含まれる場合）。
- **サービスの改善：** ウェブサイトの利用状況を分析し、技術的な問題を特定して、機能と安全性を改善します。

当社は以下の状況においてお客様の個人情報を共有する場合があります：

- **サービスプロバイダーとの共有：** ホスティング、データ保存、認証、メール配信、解析、セッションのおおよその位置の照会に外部サービスを使用します。ログインには Google または GitHub、プロフィール画像には Cloudflare R2、メールには Resend、解析が有効な場合は Umami を使用します。各機能に必要な情報は、それぞれのサービスプロバイダーによって処理されます。
- **事業譲渡のため：** 合併、会社資産の売却、資金調達、または当社事業の全部もしくは一部の別の会社への取得に関連して、またはその交渉中に個人情報を共有または移転する場合があります。
- **アフィリエイトと：** アフィリエイトと情報を共有する場合があります。その場合、当社はアフィリエイトにこのプライバシーポリシーを遵守するよう求めます。アフィリエイトには、親会社および他の子会社、合弁会社パートナー、または当社が支配または支配下にある他の会社が含まれます。
- **他のユーザーとの共有：** ウェブサイトに投稿すると、表示名、プロフィール画像、コメント、ゲストブックのメッセージが公開される場合があります。公開したくない情報を含めないでください。
- **お客様の同意を得て：** その他の目的でお客様の個人情報をお客様の同意を得て開示する場合があります。

### お客様の個人データの保持

会社は、このプライバシーポリシーで定められた目的に必要な期間のみお客様の個人データを保持します。当社は、法的義務を遵守するために必要な範囲でお客様の個人データを保持・使用します（例えば、適用法に従ってデータを保持する必要がある場合）、紛争を解決し、法的合意および方針を執行します。

また、内部分析目的のために利用データを保持します。利用データは一般的により短い期間保持されますが、このデータが当社のサービスのセキュリティを強化または機能を改善するために使用される場合、または当社がより長い期間このデータを保持する法的義務がある場合は除きます。

### お客様の個人データの移転

お客様の情報（個人データを含む）は、会社の運営オフィスおよびその処理に関わる当事者が所在するその他の場所で処理されます。これは、この情報がお客様の州、県、国または他の政府管轄区の外に移転され、データ保護法がお客様の管轄区と異なる可能性のある国のコンピューターに保持される可能性があることを意味します。

このプライバシーポリシーへのお客様の同意と、その後のそのような情報の提出は、その移転への同意を意味します。

会社は、お客様のデータが安全に、かつこのプライバシーポリシーに従って取り扱われることを確保するために合理的に必要なすべての措置を講じ、お客様の個人データが、お客様のデータおよびその他の個人情報のセキュリティを含む適切な管理が整っていない限り、組織または国への移転は行われません。

### お客様の個人データの削除

お客様は、当社が収集したお客様に関する個人データを削除するか、削除を支援するよう要請する権利があります。

アカウント設定で表示名やプロフィール画像の編集、通知設定の管理ができ、用意された操作で自分のコメントやゲストブックのメッセージを削除できます。

アカウントやその他の個人データへのアクセス、訂正、削除を希望する場合は、hello@nelsonlai.dev までご連絡ください。現在、アカウント設定にはアカウントを自分で削除する機能はありません。

ただし、当社が法的義務または合法的な根拠がある場合は、特定の情報を保持する必要がある場合があることをご注意ください。

#### その他の法的要件

会社は、以下の目的のために必要であると誠実に信じる場合、お客様の個人データを開示する場合があります：

- 法的義務を遵守するため
- 会社の権利または財産を保護・防衛するため

お客様の個人データのセキュリティは当社にとって重要ですが、インターネット経由の送信や電子的な保存には、100%安全な方法はないことを忘れないでください。当社はお客様の個人データを保護するために商業的に許容できる手段を使用するよう努めていますが、その絶対的なセキュリティを保証することはできません。

## 子供のプライバシー

当社のサービスは13歳未満の方を対象としていません。当社は13歳未満の方から故意に個人を特定できる情報を収集しません。お客様が保護者であり、お子様が当社に個人データを提供したことに気づいた場合は、当社にご連絡ください。当社が保護者の同意確認なしに13歳未満の方から個人データを収集したことに気づいた場合、当社のサーバーからその情報を削除するための措置を講じます。

お客様の情報の処理の法的根拠として同意に依存する必要があり、お客様の国が親からの同意を要求する場合、当社はその情報を収集・使用する前にお客様の親の同意を必要とする場合があります。
