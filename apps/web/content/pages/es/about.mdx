## Quién soy

Soy un Ingeniero Full Stack en Hong Kong. Estoy aprendiendo TypeScript, Next.js/TanStack Start, React.js, Node.js y gestión de bases de datos. Ahora tengo pasión por aprender UI/UX.

Empecé a aprender desarrollo web el 5 de diciembre de 2020 (tenía 14 años). Es un gran desafío porque es solo uno de mis pasatiempos y aún no he tomado ningún curso. Aprendo de forma autodidacta en YouTube. Uno de mis canales favoritos es [The Net Ninja](https://www.youtube.com/@NetNinja). Aprendí muchas habilidades de desarrollo web de él.

Me encanta usar [Next.js](https://nextjs.org/)/[TanStack Start](https://tanstack.com/start/latest) para crear un sitio web. Luego uso [GitHub](https://github.com) para alojar mi código. Después, uso [Docker](https://www.docker.com/) para desplegar mi sitio web.

## Acerca de este sitio

- Framework: [TanStack Start](https://tanstack.com/start/latest)
- Base de datos: [PostgreSQL](https://www.postgresql.org/)
- ORM: [Drizzle](https://orm.drizzle.team/)
- Autenticación: [Better Auth](https://www.better-auth.com/)
- Despliegue: [Docker](https://www.docker.com/)
- Contenido: [MDX](https://mdxjs.com/)
- Análisis: [Umami](https://github.com/umami-software/umami)
- Estilos: [Tailwindcss](https://tailwindcss.com)

La primera versión de este sitio se inspiró en [tailwind-nextjs-starter-blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) de **Timothy Lin**. Me ayudó a empezar a crear un blog desde cero, y el sitio ha evolucionado considerablemente desde entonces.
