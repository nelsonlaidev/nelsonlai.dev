本隱私權政策描述了我們在您使用本服務時，關於收集、使用和披露您的資訊的政策和程序，並告知您有關您的隱私權利以及法律如何保護您。

我們使用您的個人資料來提供和改進本服務。使用本服務即表示您同意根據本隱私權政策收集和使用資訊。

## 解釋與定義

### 解釋

以下詞彙在本文件中具有下列定義；單數與複數用法具有相同含義。

### 定義

為本隱私權政策之目的：

- **帳戶**指為您建立的用於存取我們的服務或服務部分的唯一帳戶。
- **關聯公司**指控制、被控制或與某一方共同控制的實體，其中「控制」指擁有 50% 或以上的股份、股權或其他有權投票選舉董事或其他管理權的證券。
- **公司**（在本協議中稱為「公司」、「我們」或「我們的」）指 nelsonlai.dev。
- **Cookie** 是網站放置在您的電腦、行動裝置或其他裝置上的小型檔案，包含您在該網站上的瀏覽歷史詳情等用途。
- **國家**指：香港特別行政區
- **裝置**指任何可以存取服務的裝置，例如電腦、手機或數位平板。
- **個人資料**指與已識別或可識別的個人相關的任何資訊。
- **服務**指網站。
- **服務提供者**指代表公司處理資料的任何自然人或法人。指公司雇用的第三方公司或個人，以促進服務、代表公司提供服務、執行與服務相關的服務或協助公司分析服務的使用情況。
- **第三方社交媒體服務**指使用者可透過其登入或建立帳戶以使用服務的任何網站或社交網路網站。
- **使用資料**指在使用服務時自動收集的資料，或從服務基礎設施本身生成的資料（例如，頁面存取的持續時間）。
- **網站**指 nelsonlai.dev，可從 [https://nelsonlai.dev](https://nelsonlai.dev) 存取。
- **您**指存取或使用服務的個人，或該個人代表其存取或使用服務的公司或其他法律實體（視情況而定）。

## 收集和使用您的個人資料

### 收集的資料類型

#### 個人資料

在使用我們的服務時，我們可能會要求您提供某些可用於聯絡或識別您的個人身分資訊。個人身分資訊可能包括但不限於：

- 姓名、電子郵件地址、個人圖片及帳戶識別碼
- 留言、留言板訊息及通知偏好設定
- 使用資料

#### 使用資料

在使用服務時會自動收集使用資料。

使用資料可能包括您的 IP 位址、瀏覽器資訊、登入時間及工作階段識別碼。我們使用這些資訊保護帳戶並顯示有效的工作階段，也會從 IP 位址產生識別碼，以限制部落格的匿名按讚次數。

我們可能使用工作階段的 IP 位址查詢概略位置，並顯示在有效工作階段清單中。查詢時需要將該 IP 位址傳送給位置查詢服務。

啟用分析功能時，我們使用 Umami 了解網站的造訪情況。其分析程式會記錄頁面瀏覽、來源頁面、瀏覽器、作業系統、裝置類型及概略位置，不使用分析 Cookie。

#### 來自第三方社交媒體服務的資訊

公司允許您透過以下第三方社交媒體服務建立帳戶並登入以使用服務：

- Google
- GitHub

當您使用 Google 或 GitHub 登入時，我們會收到身分驗證所需的帳戶資訊，例如供應商帳戶識別碼、姓名、電子郵件地址及個人圖片。我們不會要求存取您的聯絡人清單。

您也可以透過網站提供顯示名稱、個人圖片、留言、留言板訊息及通知偏好設定。我們使用這些資訊提供您選擇使用的功能。

#### 追蹤技術和 Cookie

我們使用 Cookie 進行身分驗證並記住語系偏好，也使用瀏覽器儲存空間記住佈景主題。啟用分析功能時，亦會使用 Umami 分析程式了解網站使用情況。

- **Cookie 或瀏覽器 Cookie。** Cookie 是放置在您的裝置上的小型檔案。您可以指示您的瀏覽器拒絕所有 Cookie 或在發送 Cookie 時進行提示。然而，如果您不接受 Cookie，您可能無法使用我們服務的某些部分。除非您已調整瀏覽器設定以拒絕 Cookie，否則我們的服務可能會使用 Cookie。
- **分析。** 啟用時，Umami 會收集網站使用統計資料，不使用分析 Cookie，以協助我們了解哪些頁面被瀏覽並改善網站。

Cookie 可以是「持續性」或「工作階段」Cookie。持續性 Cookie 在您離線時保留在您的個人電腦或行動裝置上，而工作階段 Cookie 在您關閉網頁瀏覽器時即被刪除。

我們出於以下目的使用工作階段和持續性 Cookie：

- **必要/基本 Cookie**

  類型：依身分驗證流程使用工作階段或持續性 Cookie

  管理方：我們

  目的：這些 Cookie 對於透過網站提供給您的服務以及使您能夠使用其某些功能至關重要。它們有助於驗證使用者並防止欺詐性使用使用者帳戶。如果沒有這些 Cookie，您要求的服務無法提供，我們僅使用這些 Cookie 為您提供這些服務。

- **功能性 Cookie**

  類型：持續性 Cookie

  管理方：我們

  目的：這些 Cookie 會記住您的語系偏好。我們也使用瀏覽器儲存空間記住您的佈景主題，讓您不必在每次造訪時重新選擇。

您可以在瀏覽器設定中管理 Cookie 及儲存空間。封鎖身分驗證 Cookie 可能導致無法登入。如對這些技術有疑問，請來信 hello@nelsonlai.dev。

### 個人資料的使用

公司可能出於以下目的使用個人資料：

- **提供和維護我們的服務**，包括監控我們服務的使用情況。
- **管理您的帳戶：** 管理您作為服務使用者的註冊。您提供的個人資料可以讓您存取作為註冊使用者可用的服務的不同功能。
- **聯絡您：** 依通知偏好設定寄送留言及回覆通知，並回應您透過電子郵件提出的請求。
- **管理您的請求：** 處理和回應您的請求。
- **業務轉讓：** 我們可能使用您的資訊來評估或進行合併、剝離、重組、解散或其他出售或轉讓我們的部分或全部資產，無論是作為持續經營還是作為破產、清算或類似程序的一部分，其中我們持有的關於服務使用者的個人資料是轉讓的資產之一。
- **改善服務：** 分析網站使用情況、找出技術問題，並改善功能與安全性。

我們可能在以下情況下分享您的個人資料：

- **與服務提供者：** 我們使用網站託管、資料儲存、身分驗證、電子郵件傳送、分析及工作階段概略位置查詢服務，包括用於登入的 Google 或 GitHub、儲存個人圖片的 Cloudflare R2、寄送電子郵件的 Resend，以及啟用分析時使用的 Umami。各項功能所需的資訊會由對應的服務提供者處理。
- **業務轉讓：** 我們可能在與任何合併、公司資產出售、融資或收購我們全部或部分業務的談判中分享或轉讓您的個人資料。
- **與關聯公司：** 我們可能與我們的關聯公司分享您的資訊，在這種情況下，我們將要求這些關聯公司遵守本隱私權政策。關聯公司包括我們的母公司以及我們控制或與我們共同控制的任何其他子公司、合資企業合作夥伴或其他公司。
- **與其他使用者：** 當您在網站發表內容時，您的顯示名稱、個人圖片、留言及留言板訊息可能公開顯示。請勿包含您不希望公開的資訊。
- **經您的同意：** 我們可能在您同意的情況下為任何其他目的披露您的個人資料。

### 個人資料的保留

公司將僅在為本隱私權政策中規定的目的所需的時間內保留您的個人資料。我們將在必要範圍內保留和使用您的個人資料，以履行我們的法律義務（例如，如果我們需要保留您的資料以遵守適用法律）、解決爭議並執行我們的法律協議和政策。

公司還將保留使用資料用於內部分析目的。使用資料通常保留的時間較短，除非這些資料用於加強安全性或改進我們服務的功能，或者我們在法律上有義務保留這些資料更長時間。

### 個人資料的轉移

您的資訊，包括個人資料，在公司的營運辦公室以及參與處理的其他地點進行處理。這意味著這些資訊可能被轉移到您所在的州、省、國家或其他政府管轄區以外的電腦上並在那裡維護，這些地方的資料保護法律可能與您所在的管轄區不同。

您同意本隱私權政策並提交此類資訊即表示您同意該轉移。

公司將採取所有合理必要的措施，以確保您的資料得到安全處理並符合本隱私權政策，且除非有適當的控制措施（包括您的資料和其他個人資料的安全性），否則不會將您的個人資料轉移到任何組織或國家。

### 刪除您的個人資料

您有權刪除或要求我們協助刪除我們收集的關於您的個人資料。

您可以在帳戶設定中編輯顯示名稱與個人圖片、管理通知偏好，並透過現有功能刪除自己的留言或留言板訊息。

如需查閱、更正或刪除帳戶及其他個人資料，請來信 hello@nelsonlai.dev。目前帳戶設定尚未提供自行刪除帳戶的選項。

請注意，我們可能需要在有法律義務或合法依據時保留某些資訊。

### 個人資料的披露

#### 業務交易

如果公司涉及合併、收購或資產出售，您的個人資料可能會被轉移。我們將在您的個人資料被轉移並受不同隱私權政策約束之前提供通知。

#### 執法

在某些情況下，如果法律要求或應公共當局（例如法院或政府機構）的有效請求，公司可能需要披露您的個人資料。

#### 其他法律要求

公司可能出於善意相信必須採取以下行動披露您的個人資料：

- 遵守法律義務
- 保護和捍衛公司的權利或財產
- 防止或調查與服務相關的可能不當行為
- 保護服務使用者或公眾的個人安全
- 防止法律責任

### 個人資料的安全性

您的個人資料的安全性對我們很重要，但請記住，網路上的傳輸方法或電子儲存方法都不是 100% 安全的。雖然我們努力使用商業上可接受的手段來保護您的個人資料，但我們無法保證其絕對安全。

## 兒童隱私

我們的服務不針對 13 歲以下的任何人。我們不會故意收集 13 歲以下任何人的個人身分資訊。如果您是父母或監護人，並且您知道您的孩子向我們提供了個人資料，請聯絡我們。如果我們發現我們在未經父母同意驗證的情況下收集了 13 歲以下任何人的個人資料，我們將採取措施從我們的伺服器中刪除該資訊。

如果我們需要依賴同意作為處理您的資訊的法律依據，且您的國家要求父母同意，我們可能在收集和使用該資訊之前需要您的父母同意。

我們的服務可能包含指向我們不營運的其他網站的連結。如果您點擊第三方連結，您將被定向到該第三方網站。我們強烈建議您審查您存取的每個網站的隱私權政策。

我們對任何第三方網站或服務的內容、隱私權政策或做法沒有控制權，也不承擔任何責任。

## 本隱私權政策的變更

我們可能會不時更新我們的隱私權政策。我們將透過在此頁面上發布新的隱私權政策來通知您任何更改。

我們將透過電子郵件和/或在我們的服務上顯著通知您，在更改生效之前，並更新本隱私權政策底部的「最後更新」日期。

建議您定期審查本隱私權政策以了解任何更改。本隱私權政策的更改在發布到此頁面時生效。
