## Quem sou eu

Sou um Engenheiro Full Stack em Hong Kong. Estou aprendendo TypeScript, Next.js/TanStack Start, React.js, Node.js e gerenciamento de banco de dados. Atualmente, tenho uma paixão por aprender UI/UX.

Comecei a aprender desenvolvimento web em 5 de dezembro de 2020 (eu tinha 14 anos). É um grande desafio porque é apenas um dos meus hobbies e ainda não fiz nenhum curso. Sou autodidata através do YouTube. Um dos meus canais favoritos no YouTube é o [The Net Ninja](https://www.youtube.com/@NetNinja). Aprendi muitas habilidades de desenvolvimento web com ele.

Eu adoro usar [Next.js](https://nextjs.org/)/[TanStack Start](https://tanstack.com/start/latest) para criar um site. Em seguida, uso o [GitHub](https://github.com) para hospedar minha base de código. Depois disso, uso o [Docker](https://www.docker.com/) para implantar meu site.

## Sobre este site

- Framework: [TanStack Start](https://tanstack.com/start/latest)
- Banco de dados: [PostgreSQL](https://www.postgresql.org/)
- ORM: [Drizzle](https://orm.drizzle.team/)
- Autenticação: [Better Auth](https://www.better-auth.com/)
- Implantação: [Docker](https://www.docker.com/)
- Conteúdo: [MDX](https://mdxjs.com/)
- Análise: [Umami](https://github.com/umami-software/umami)
- Estilização: [Tailwindcss](https://tailwindcss.com)

A primeira versão deste site foi inspirada no [tailwind-nextjs-starter-blog](https://github.com/timlrx/tailwind-nextjs-starter-blog) de **Timothy Lin**. Ele me ajudou a começar a criar um blog do zero, e o site evoluiu bastante desde então.
