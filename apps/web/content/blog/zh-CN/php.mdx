## PHP 简介

PHP（全名：PHP: _Hypertext Preprocessor_）是一种开源的通用计算机脚本语言，特别适合用于网页开发并嵌入到 HTML 中。PHP 的语法借鉴了 C 语言、Java 和 Perl 等流行计算机语言的特点，对于一般程序员来说易于学习。PHP 的主要目标是让网页开发人员快速编写动态页面，但 PHP 也用于许多其他领域。

PHP 文件的后缀名为 `.php`，例如 `index.php`。如上所述，`PHP` 可以直接嵌入到 `HTML` 中。

## 用法

在 Web 应用中，PHP 在服务器端执行。PHP 解释器执行 `<?php` 和 `?>` 之间的代码，再由服务器将输出结果发送给浏览器。例如：

```php
<!DOCTYPE html>
<html>
    <head>
        <title>PHP</title>
    </head>
    <body>
        <?php
            echo "这是一个句子。"
        ?>
    </body>
</html>
```

## 注意事项

如果文件仅包含 PHP 代码，或以 PHP 代码结尾，建议省略最后的 `?>`，避免意外输出末尾的空白或换行。将 PHP 嵌入 HTML 时，则可以使用 `?>` 结束 PHP 代码块，继续编写 HTML。

```php
<?php
    echo "PHP 结束后没有 HTML";
```

## PHP 注释

几乎所有的网页程序语言都可以使用注释，`PHP` 的**单行注释**使用 `//`，**多行注释**使用 `/* Some text here */`。

```php
<?php
    echo "这是一个单行注释"; // 我是一个单行注释
    echo "这是一个多行注释";
    /*
        我是一个多行注释
        第二行
    */
?>
```

## Echo

使用 `echo` 可以输出文本或表达式的结果。字符串字面量可以用双引号 `""` 或单引号 `''` 括起来。每条 `echo` 语句都以分号 `;` 结尾。

```php
<?php
    echo "这是使用双引号的示例。";
    echo '这是使用单引号的示例。';
?>
```

在 `echo` 的内容中还可以使用 `HTML` 语法。例如，使用 `<br/>` 来换行。

```php
<?php
    echo "这是第一句<br/>";
    echo "这是第二句";
    echo "<a href=\"https://example.com\">这是一个链接</a>";
?>
```

## 变量

我们可以将值分配给变量，使我们更容易编写 `PHP`，类似于 `JavaScript`。我们将使用美元符号 `$`。

```php
<?php
    $value = "我是变量值";
?>
```

命名变量时需要遵循一些规则。

变量名区分大小写：`$value` 和 `$Value` 是不同的变量，即使它们存储相同的值。

## 变量命名技巧

### 驼峰式命名法

当变量名称和函数名称由两个或多个单词组合而成时，使用 "驼峰式命名法" 可以提高变量和函数的可读性，因为变量中不能有空格。

```php
<?php
    $onePlusOneAnswer = 1 + 1;
    echo $onePlusOneAnswer;
?>
```

### 蛇形命名法

蛇形命名法（如 snake_case）是指每个空格用下划线（ \_ ）字符替代，并且每个单词的首字母用小写。

```php
<?php
    $one_plus_one_answer = 1 + 1;
    echo $one_plus_one_answer;
?>
```

## 字符串运算符

有两种字符串运算符。第一种是连接运算符（"."），它返回左右参数连接后的字符串。第二种是连接赋值运算符（".="），它将右侧参数附加到左侧参数。

```php
<?php
    echo "这是" . " " . "字符串" . " " . "运算符" . "。";
?>
```

## 算术运算符

```php
<?php
    $value0 = 1.5; // 浮点数
    $value1 = 1 + 1; // 加
    $value2 = 1 - 1; // 减
    $value3 = 1 * 1; // 乘
    $value4 = 1 / 1; // 除
    $value5 = 12 / 5; // 除法：结果为 2.4
    $value6 = 3 % 5; // 取余数
?>
```
