## Introdução ao PHP

O PHP (nome completo: PHP: _Hypertext Preprocessor_) é uma linguagem de script de computador de uso geral de código aberto, especialmente adequada para o desenvolvimento da web e incorporada em HTML. A sintaxe do PHP baseia-se nas características das linguagens de computador populares, como a linguagem C, Java e Perl, e é fácil de aprender para programadores em geral. O objetivo principal do PHP é permitir que os desenvolvedores web escrevam rapidamente páginas dinâmicas, mas o PHP também é usado em muitas outras áreas.

Os arquivos PHP usam a extensão `.php`, como em `index.php`. O código PHP pode ser inserido diretamente no HTML.

## Uso

Em uma aplicação web, o PHP é executado no servidor. O interpretador PHP executa o código entre `<?php` e `?>`, e o servidor envia o resultado ao navegador. Por exemplo:

```php
<!DOCTYPE html>
<html>
    <head>
        <title>PHP</title>
    </head>
    <body>
        <?php
            echo "Esta é uma frase.";
        ?>
    </body>
</html>
```

## Precauções

Se um arquivo contém apenas código PHP ou termina com código PHP, omita a tag final `?>` para evitar espaços ou quebras de linha acidentais na saída. Ao incorporar PHP em HTML, use `?>` para voltar ao HTML fora do bloco PHP.

```php
<?php
    echo "Nenhum HTML após o PHP terminar";
```

## Comentários PHP

A maioria das linguagens de programação web pode comentar, e a forma de **linha única** do `PHP` é `//` e a forma de **várias linhas** é `/* Algum texto aqui */`.

```php
<?php
    echo "Este é um comentário de uma linha"; // Sou um comentário de uma linha
    echo "Este é um comentário de várias linhas";
    /*
        Sou um comentário de várias linhas
        Segunda linha
    */
?>
```

## Echo

Use `echo` para exibir texto ou o resultado de uma expressão. Strings podem ser delimitadas por aspas duplas `""` ou simples `''`. Termine cada instrução `echo` com um ponto e vírgula `;`.

```php
<?php
    echo "Este é o exemplo de usar aspas duplas.";
    echo 'Este é o exemplo de usar aspas simples.';
?>
```

O conteúdo no `echo` também pode usar a sintaxe do `HTML`. Por exemplo, eu usei `<br/>` aqui, para que a linha possa ser quebrada.

```php
<?php
    echo "Esta é a primeira frase<br/>";
    echo "Esta é a segunda frase";
    echo "<a href=\"https://example.com\">aqui está um link</a>";
?>
```

## Variável

Assim como em JavaScript, em PHP você pode atribuir valores a variáveis. Em PHP, os nomes das variáveis começam com um cifrão (`$`).

```php
<?php
    $value = "Sou um valor";
?>
```

Há algumas regras a serem seguidas ao nomear variáveis.

Os nomes de variáveis diferenciam maiúsculas de minúsculas: `$value` e `$Value` são variáveis diferentes, mesmo que contenham o mesmo valor.

## Dicas para nomeação de variáveis

### Camel case

Em camel case, as palavras são escritas sem espaços. A primeira começa com letra minúscula e cada uma das seguintes começa com letra maiúscula. Isso facilita a leitura de nomes de variáveis e funções formados por várias palavras.

```php
<?php
    $onePlusOneAnswer = 1 + 1;
    echo $onePlusOneAnswer;
?>
```

### Snake case

Em snake case, todas as palavras são escritas em letras minúsculas e separadas por sublinhados, como em `snake_case`.

```php
<?php
    $one_plus_one_answer = 1 + 1;
    echo $one_plus_one_answer;
?>
```

## Operador de string

O PHP tem dois operadores de string. O operador de concatenação (`.`) une duas strings. O operador de atribuição por concatenação (`.=`) acrescenta o valor à direita ao final da string armazenada na variável à esquerda.

```php
<?php
    echo "Isso" . " " . "é" . " " . "Operadores" . " " . "de string" . ".";
?>
```

## Operador aritmético

```php
<?php
    $value0 = 1.5; // Número de ponto flutuante
    $value1 = 1 + 1; // Mais
    $value2 = 1 - 1; // Menos
    $value3 = 1 * 1; // Vezes
    $value4 = 1 / 1; // Dividir
    $value5 = 12 / 5; // Divisão: o resultado é 2.4
    $value6 = 3 % 5; // Pegar o resto
?>
```
