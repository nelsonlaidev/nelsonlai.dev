Scoutly 是一款快速、轻量级的网站爬虫与 SEO 分析工具。我在 2025 年 11 月为了练习 Rust 而启动这个项目。此项目灵感源自 [Scrutiny](https://peacockmedia.software/mac/scrutiny/)。

Scoutly 以可配置的深度、页数、并发度与请求速率限制爬取同源 HTML 页面，遵守 robots.txt，并从 XML sitemap 发掘页面。它会检查发现的链接与图片，并找出与页面标题、元描述、H1 标题及缺少图片替代文本相关的常见 SEO 问题。结果可在通过键盘操作的终端界面（TUI）中浏览，或以纯文本与 JSON 报告输出；爬虫核心也同时以 Rust 库的形式提供。
