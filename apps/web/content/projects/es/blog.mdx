Mi sitio web personal y blog.

Después de ver otros sitios web y blogs, quise crear mi propio blog para escribir con libertad, ya fueran tutoriales, notas o entradas de diario. Por eso empecé a aprender habilidades de desarrollo web el 5 de diciembre de 2020. Primero aprendí HTML, CSS y JavaScript. Al cabo de un año, descubrí que un sitio web estático no era suficiente para mí. Entonces empecé a aprender React.js y luego Next.js.
