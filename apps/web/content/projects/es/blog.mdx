Mi sitio web personal y blog.

He visto muchos sitios web en Internet. Me preguntaba si podría crear mi propio blog donde pudiera escribir lo que quisiera. Ya sea tutoriales, notas o diarios. Por eso empecé a aprender habilidades de desarrollo web el 5 de diciembre de 2020. Primero aprendí HTML, CSS y JavaScript. Al cabo de un año, descubrí que un sitio web estático no era suficiente para mí. Entonces empecé a aprender React.js y luego Next.js.
