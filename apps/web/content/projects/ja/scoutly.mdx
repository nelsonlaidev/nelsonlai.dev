Scoutly は、高速・軽量なウェブクローラー兼 SEO アナライザーです。2025 年 11 月に Rust の練習として開発を始めました。[Scrutiny](https://peacockmedia.software/mac/scrutiny/) にインスパイアされたプロジェクトです。

Scoutly は、深さ・ページ数・並行度・リクエストレートの上限を設定して同一オリジンの HTML ページをクロールし、robots.txt を尊重し、XML サイトマップからページを発見します。見つかったリンクと画像を検査し、ページタイトル、メタディスクリプション、H1 見出し、画像の代替テキストの欠如に関する一般的な SEO 問題を指摘します。結果はキーボード操作の TUI で閲覧できるほか、テキストや JSON レポートとして出力でき、クローラーはインポート可能な Rust ライブラリとしても利用できます。
