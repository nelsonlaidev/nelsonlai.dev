Eu tenho muitas ideias malucas, e uma delas é executar o Zsh no navegador. Eu uso Zsh há muito tempo e adoro. Então, estou tentando criar o Zsh Web. É um terminal baseado na web que executa o Zsh no navegador de forma simulada. Foi construído com Next.js e TypeScript.
