我有很多瘋狂的想法，其中之一就是在瀏覽器中運行 Zsh。我使用 Zsh 已經很長時間了，我非常喜歡它。所以，我嘗試創建 Zsh Web。這是一個在瀏覽器中模擬 Zsh 的網頁終端。它是用 Next.js 和 TypeScript 構建的。
