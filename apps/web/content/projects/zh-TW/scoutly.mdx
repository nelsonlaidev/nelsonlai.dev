Scoutly 是一款快速、輕量級的網站爬蟲與 SEO 分析工具。我在 2025 年 11 月為了練習 Rust 而展開這個專案。此專案靈感源自 [Scrutiny](https://peacockmedia.software/mac/scrutiny/)。

Scoutly 以可設定的深度、頁數、並行度與請求速率限制爬取同源 HTML 頁面，遵守 robots.txt，並從 XML sitemap 發掘頁面。它會檢查發現的連結與圖片，並找出與頁面標題、中繼描述、H1 標題及缺少圖片替代文字相關的常見 SEO 問題。結果可在透過鍵盤操作的終端機介面（TUI）中瀏覽，或以純文字與 JSON 報告輸出；爬蟲核心也同時以 Rust 函式庫的形式提供。
